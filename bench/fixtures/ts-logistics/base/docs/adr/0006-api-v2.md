# ADR-0006: Public API v2

Status: Accepted (2023-11)

## Decision

- Resource-oriented routes under `/v2` (quotes, shipments, tracking).
- Authentication by API key (`x-api-key` or `Authorization: Bearer`) mapped
  to a tenant; tenant scopes gate each route.
- Amounts in minor units, line items carry stable public codes
  (`packages/core/src/codes/lineItemCodes.ts`).
- v1 stays available until all integrators have migrated.
